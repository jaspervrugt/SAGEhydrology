What SAGE should do

I would not replace 22.68 km² with 895 km² automatically. The 895 km² value is only the area that forces Q/P=1 using ERA5-Land precipitation; 
it is not an independently established physical catchment area.

The safest treatment is:

Flag station il_30131 as a non-closed, karst/spring-fed basin.
Exclude it from conventional rainfall–runoff calibration and water-balance checks.
Retain the raw discharge in m³/s for inspection.
Do not interpret its converted discharge in mm/day using 22.683379 km².
Add a warning whenever this station is selected.
