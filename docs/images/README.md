# SAGE graphical interface figures

The screenshots in this directory illustrate the public SAGE workflow:

1. `sage-notes-run-summary.png` — Notes workspace and completed-run summary.
2. `sage-data-quality-regional-coverage.png` — Data-quality screening and regional coverage.
3. `sage-data-installation-basin-map.png` — Region and dataset selection with data-installation controls on the left; live loss-function, median performance, and integrated basin-score trajectories on the right.
4. `sage-matlab-export-script.png` — Reproducible MATLAB script exported from the GUI.

The main repository README displays reduced versions linked to the original-resolution files.
